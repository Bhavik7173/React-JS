CSS : cascading style sheets

syntax :
    selector {property:value}

    h1{color:red}
    p{font-size:20px;
    padding:10px;
    margin:5px;}
where
    selector
        HTML element    => HTML_TAG{property:value}
        id selector     => #id_name{property:value}
        class selector  => .class_name{property:value}
        universal selector

Integrate CSS in HTML
    - Internal : <style></style> ==> head tag
    - External : <link>
    - Inline   : add css property to the tag
